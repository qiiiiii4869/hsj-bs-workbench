## 计算规则与源码证据

- `T3DFreqDataSet.cpp::GetMultiChnData`：按试验类型收集各参数工况，std::map 按工况名称排序；`SetFFTData / SetWaveData`：X 为参考通道全段原始数据均值，Y 为频率或时间，Z 为频谱幅值或原始波形。波形页的滤波、当前视区及置信度不会附加到三维图。
- `Ni3DWaveView.cpp:328`：三维整周期独立采用 `[int(first_key), int(last_key)-1)`，与波形频谱页不同。本次没有复用波形页的 FFT 输出。
- `T3DFreqDataSet.cpp:459`：原类在遍历参数时保留同一份键相成员，结束后使用首个参数工况的键相；本版显式保留这项原行为。不能将其描述为每个工况各自解码后独立取整周期。
- `Ni3DWaveView.cpp:417`：即使 FFT 输入已被截成 M 点，幅值缩放仍为 `2*abs(FFT)/N`，频率间隔仍为 `Fs/N`，N 为原始通道长度；保留前 `N//2` 个 FFT 系数，DC 为零。`stdafx.h:66` 的 bRetime 为 FALSE，本版不重采样、不预去均值、不附加其他窗。
- 对共享键相不足、整周期短到无法满足原谱线索引等原版边界，明确报错，不补零或生成无意义谱线。完整计算后才做显示用分段极值抽样，每曲线约 6000 点，保留各段极值；不是使用抽样后的数据计算 FFT。
- `waterfall.py` 提供数据准备，`analysis_service.py` 统一计算互斥，`api.py` 增加 `/api/waterfall-data`；OpenAPI 文档同步登记。浏览器 `waterfall.js` 进行旋转投影、三维范围线段裁剪和绘制。

## 保存和取消

单图保存实际画布；非 PNG 通过已有图像转换接口转换。批量使用独立离屏画布，保留当前图及视角，逐通道完成后打包；取消会等待正在处理的当前通道结束，不下载部分结果。逐项失败记录在界面和 ZIP 的“导出记录.json”中。ZIP 使用 UTF-8 文件名和 CRC32，不引入外部图形或打包 CDN。

标题、坐标、字体、曲线设置弹窗取消时保留原状态。字体是浏览器可用字体，输入未安装的名称时由系统回退。新建窗口参数可修改；当前图仅在新建成功后替换。

新建参数按“分拣文件 → 试验类型 → 参数 / 预览工况 → 通道数据 → 参考通道”逐级解锁，初始只允许选择文件，不自动选择默认值。切换上一级会清空下游选择及旧预览；上一级未选、文件读取失败或正在处理时，下游保持灰显。全部选择有效且预览读取结束后才能确定；索引 0 作为有效选择处理。取消未完成的新建不改变当前图的批量导出数据来源。
