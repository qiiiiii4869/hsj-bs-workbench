# HSJ 本机浏览器分析版

这是 HSJ 本机浏览器实现，**尚未完成整程序用户验收**。完整功能保留要求以 `frontend-review/功能保留清单.md` 为准；70 项要求及全部 CMD/资源/控件/事件证据见本目录的 `功能迁移对照表.md` 和 `migration-ledger.json`。

用户已明确指定《功能保留清单》和《功能入口与源码证据》作为迁移基线。当前波形/频谱的实现与缺口逐项列在 `波形频谱逐项迁移核对.md`；新增辅助功能不抵销原有待迁移项，已接入不等于已验收。

## 启动与关闭

1. 双击根目录的 `启动浏览器分析版.cmd`。浏览器打开多视图工作区 `http://127.0.0.1:8765/desktop`。
2. 首次自动读取项目中的“电厂变负荷.SEL”。也可以切换其他项目文件或导入自己的 SEL。
3. 选择工况与通道，设置时间范围和 FFT 窗，点击“开始分析”。滚轮缩放 X 轴、拖动平移、双击复位。频谱提供低频范围选择。
4. 波形和频谱可导出完整分析区间 CSV；JSON 保存统计、谱线、参数、文件 SHA256 和用于显示的极值抽样数据。
5. 右上角“查看迁移对照”查看全部功能范围和当前缺口。
6. 双击 `停止浏览器分析版.cmd` 停止由启动器管理的后台服务。关闭浏览器不会停止服务。

当前版本为 **0.17-orbit-classic-layout**（2026-11-10）。本轮继续补齐多文件 / 多视图、专项操作细节、原版结果文件、报表与批量流程；完整说明见 `实现补齐交付记录.md`，70项功能代码入口见 `功能实现索引.json`。按用户要求，本轮未运行测试，仅启动新服务交付，既有验收记录不扩大。

提供三种图表显示模式、95%/97%/100% 峰峰值、四类 Butterworth 滤波、连续应用/逐步撤销/恢复、各工况通道独立记忆设置、原始与滤波后波形/频谱叠加、原始对照 CSV、滤波结果及全时段 CSV/JSON、标题修改。滤波和标题弹窗支持取消；Esc 关闭未提交的弹窗不更改已生效参数。详见 `滤波模块交付说明.md`。

当前电脑使用 `bs-workbench/.venv` 中的 Python 3.13 环境，复用本机已存在的 NumPy、Pillow、python-docx、openpyxl 等依赖；启动器会检查所需模块，没有修改全局 Python 依赖。其他电脑使用 Python 3.11+ 后运行 `python -m pip install -r bs-workbench/requirements.txt`。本目录不是免安装包。原桌面源码、资源和示例数据不修改，上传文件保存为 `bs-workbench/data/<UUID>.sel/.chd`，批量包保存于 `data/exports`。

启动日志位于 `.runtime/server.out.log` 和 `.runtime/server.err.log`。重复启动会复用本程序的健康服务。默认端口占用且不是本服务时会报错，不终止其他程序。

## 当前实际架构

```text
浏览器：HTML / CSS / JavaScript / Canvas
    │ 同源 JSON / 二进制上传 / CSV 下载
    ▼
Uvicorn：127.0.0.1:8765（单进程、本机使用）
    ▼
FastAPI 接口层：api.py
    ├── 本机会话、请求校验、分块上传、下载与静态资源
    └── 在线程池执行同步分析接口
    ▼
分析业务层：analysis_service.py
    ├── 文件目录、SEL / CHD 解析与分析调度
    ├── analysis：NumPy 统计/FFT、SciPy Butterworth 滤波
    └── 捡取 / 标注、叠加 / 趋势、长图、报表与批量输出
    ▼
原始 SEL / 导入副本 / JSON 分析记录 / CSV 结果
```

前端仍为原生 JavaScript / Canvas，当前没有引入 Vue、通用任务队列或数据库；协联使用从原 C++ 数值代码构建的独立进程，其他专项采用 Python 实现；批量导出继续使用既有后台线程任务。`server.py` 保留为 Windows 启动脚本调用的入口，接口定义可从 `/api/schema` 获取，可视化调试页为 `/docs`。后续 Agent 可通过接口层调用分析业务层；本轮尚未接入模型、对话、Agent 工具编排或 SSE。框架升级不代表其余原版业务功能已迁移或验收。

## 接口文档与调试

访问 `http://127.0.0.1:8765/docs`，或通过波形与频谱页“文件 → 接口文档 / 调试”打开。Swagger UI 5.34.1 的 JS、CSS 和许可证已放在 `static/vendor/swagger-ui`，页面不从 CDN 加载资源，在线校验器关闭；授权令牌只用于当前页面，不持久化到浏览器存储。资源版本、来源和 SHA256 记录在该目录的 `manifest.json`。

页面自动从 `/api/bootstrap` 读取当前本机会话并授权 POST 接口；服务重启后点击“刷新本机会话”。也可以用 Swagger 的 Authorize 手动填写 token。展开接口后点击 Try it out，编辑示例 JSON，再点击 Execute。先读取会话和文件列表获取 file_id，再读取文件元数据获取工况/通道索引；接口分为服务、文件、分析、长图、导出、批量任务六组。

文档中的请求会执行实际计算或文件操作。下载接口标明结果媒体类型；SEL / CHD 上传提供二进制文件选择和所需请求头。接口结构包含通用字段和常用专用字段，额外业务字段仍允许传入，运行时校验沿用原接口代码。此页不包含业务系统设置或 Agent 模型配置；`/redoc` 未开启。

文档页面允许 Swagger 使用元素内联样式，脚本仍使用本地外部文件；主分析页的 CSP 保持原策略。已完成文档注册、脚本语法和资源可读性诊断，没有通过文档执行业务请求或进行浏览器功能验收。

本版仅绑定回环地址，上传接口校验会话令牌及来源，计算串行执行。它尚未提供用户身份、权限、多人隔离、远程部署或后台任务恢复，不能直接改成 `0.0.0.0` 用作内网多人版本。

## 解析与计算口径

- 格式：仅支持版本号 20091203 的 SEL；严格按 Win32 小端、4 字节 int/long、2 字节 short、4 字节 float 读取，固定头长 89569 字节，中文按 GB18030 解码。
- 对应源码：`ScanSel/SortData.cpp::ReadHead/GetSeriesPos/ReadData`、`FileData.cpp::GetDataFromFile`。有效点数沿用 `(SortEndPoint-SortStartPoint)*ChnFreq*DealSpan`，存储长度用于定位下一段，不混淆两者。原版读取不再施加 A/B 变换，本版同样不变换。
- 区间：按原版 `ceil(start/dt)`、`floor(end/dt)` 定位请求边界；有键相时默认在其中选择首尾键相点并截断为整数索引，使用 `[start_index,end_index)` 计算。实际范围在右侧显示，不与请求范围混淆；0.9 移除了 200 万点 FFT 专有限制，受本机内存与计算能力约束；上传上限仍为 256 MB。
- 统计：最大、最小、均值、中位数、95%/97%/100% 峰峰值、标准 RMS、去均值 AC RMS。置信峰峰值遵循 `GetConf` 的排序后整数下标相减规则，不使用插值分位数；CSV/JSON 记录选择的置信度。
- 滤波：四类 Butterworth（低通、高通、带通、带阻），阶数 1–100。对完整通道应用滤波后再截取分析时间，保留原版前补规则：原始点数大于 10240 时前补起始 3072 点，否则前补起始点数的十分之一；因果单向滤波后去掉前补段。使用 SciPy 二阶节分块处理，块之间延续状态，前补只在每次滤波起始执行一次。尚未证明与 NI 库数值等价。移除了最多 8 次及滤波原始点数 200 万的专有限制；分析区间仍遵守上文的 200 万点 FFT 限制，接口参数总量不超过 1 MB。恢复时从 SEL 原始值重算，不修改文件。截止频率校验仅作用于当前启用的字段，并要求严格位于 (0, Fs/2)，带通/带阻低频小于高频。
- 原界面的“有效值”：源码 `niwavefraqview.cpp` 对去均值信号计算 RMS，再乘 `2*1.41421356`。网页单独显示该值，避免和标准 RMS 混用。
- FFT：默认键相整周期（有有效键相时）、矩形窗、FFT 前不去均值；按 `2*abs(FFT)/N` 返回单边峰值幅度，DC 置零，不包含 Nyquist 点，与 `SetFraqData` 直接公式对应；提供 Hann 窗及去均值作为显式选项。按原版规则将最大的 8 个幅值映射到首次相等的谱线下标，重复幅值允许重复频率；相位保存为 0–360 度。
- 8 条结果为幅值最大的**谱线**，可能相邻，不宣称是 8 个独立局部峰。
- 原版默认置信度为 97%；旧网页错误使用 100%，已经改正。有键相时的整周期计算已接入，键相信号的完整图示/联动、多曲线等仍待迁移；原工程 `bRetime=FALSE`，没有擅自启用重采样。仍未取得 NI 桌面运行数值的完整对照证据。
- Canvas 全览按分段最小/最大值保留极值；0.5 的临近点接口从完整计算波形/频谱中按图上距离选择真实数据点，不再拿显示抽样点当完整采样点。浮动点则读取自由图面坐标，不冒充采样值。缩放或平移后可请求当前范围细节。CSV 使用完整区间数据，JSON 的曲线字段为显示数据。
- 自定义标注绑定已捡取的临近点，支持取消、修改、移动位置、删除及清除。标注按文件、工况、通道和分析数据指纹保存，图表当前范围可导出含标注 PNG；JSON/CSV 中保存标注文字、坐标、偏移和指纹。原格式 TXT、其他图像格式、全图/自定义尺寸、Office 及批量输出继续待迁移。
- 原版 `ID_Annotations` 的甩负荷专用流程未与 `ID_ANNOTATION` 自定义文字标注合并，仍待专项模块迁移。新增“标注当前范围极值”是额外入口，不作为原甩负荷标注的替代。
