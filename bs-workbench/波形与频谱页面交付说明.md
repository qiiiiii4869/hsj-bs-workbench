# 波形与频谱页面交付说明

版本：0.9-wave-workbench；日期：2026-11-08。

本次围绕用户指定的两份功能基线，将 W-01 至 W-14 和本页 E-01 至 E-08 的入口、主要处理流程与输出接入浏览器页。按用户要求未运行测试，也未做网页截图或 NI 数值回归；当前是实现交付、交用户验收，不能视作已通过完整替代验收。

## 启动

双击根目录 `重启浏览器分析版.cmd`，或在现有服务更新后刷新网页。程序默认打开“电厂变负荷.SEL”；旧的通道滤波、叠加和趋势设置仍按各自上下文保存。

## 图表与计算

- 波形/频谱/波形频谱三种模式；原文件中未启用 FFT 的通道仅开放波形显示。
- 波形 X/Y/XY 框选放大、X/XY 平移、逐步撤销与重绘；频谱 X/XY 放大、X 平移、撤销与重绘。Esc 取消进行中的框选/平移。
- 默认勾选“波形缩放/平移/撤销后自动更新统计与频谱”。计算时保留完整通道波形，当前统计/FFT 使用实际视区或其键相整周期区间，撤销可返回外层坐标。无效区间提示并回退。
- 默认 97% 峰峰值；95/97/100% 显式可选，原有效值口径和 8 条谱线的选取方式保持前述实现。
- 默认键相整周期（文件存在有效键相时），键相点显示可独立开关；非整周期分析时段使用独立弹窗，确定生效、取消保持。
- 主通道颜色可修改。标题的确定与取消、滤波及原始恢复、多通道叠加、移动趋势继续保留。
- 浮动点与完整计算数据临近点分别提供；可选择叠加或趋势曲线作为捡取目标。自定义标注绑定真实点，保存后可直接拖动文字框，曲线锚点不变。

## 两类标注与甩负荷

自定义文字标注和“甩负荷窗口与专用标注”是两个入口，没有将 ID_Annotations 与 ID_ANNOTATION 合并。

甩负荷使用窗口均值趋势，窗口宽度默认 50 点、范围 1–10000 点，步长 1 点。填写基准时刻、最终时刻，并选择上升或下降模式，生成基准、最大/最小值及变化率，同时加入两条专用标注。趋势可显隐、改色、移除和导出，设置会随通道保存。

本次明确调整的原版异常：

1. 原 `OnAnnotations` 在 `DoModal()==IDCANCEL` 分支执行计算；网页采用确定计算、取消不修改结果，避免把取消当确认。
2. 原极值文字坐标可能缺少窗口起点偏移；网页将标注锚定到实际画出的趋势点，不制造文字与锚点错位。
3. 原尾部未填满窗口的元素值缺少实测证据；甩负荷只计算完整窗口，超出其有效范围时提示缩短时段。

以上是保留功能目的时对疑似原版缺陷作出的显式处理，不宣称逐字复现旧缺陷；其数值与交互仍由用户验收。

## 数据、图像与单通道报表

“数据/图像/报表输出”中提供：

| 输出 | 内容 |
|---|---|
| 当前视图图像 | 保留当前坐标、可见叠加、图例、键相点和标注；可选单波形、单频谱或双图 |
| 完整分析区间图像 | 按最近实际计算区间绘图；包含标题、统计摘要、叠加与标注 |
| 五种图像格式 | BMP、JPG、GIF、PNG、TIFF，可设置宽高；取消不生成文件 |
| 当前时段 CHD | 数值一行一个，六位小数，沿用原 `fprintf("%lf")` 形式 |
| 全时段 CHD | 完整有效通道，经当前滤波后的波形值，不因整周期而截短 |
| 频谱结果 CHD | 原形式的分析起止时间和前 8 条序号/频率/幅值/相位表，GB18030 编码；完整频谱仍可单独导出 CSV |
| Word DOCX | 标题、文件/工况/通道/单位、统计表、波形频谱图、谱峰表、参数与输入 SHA256 |
| Excel XLSX | 汇总、统计/谱峰、图表、参数与 SHA256，并另列完整分析区间波形/频谱数据 |

Office 采用现代 DOCX/XLSX 直接生成，没有启动桌面 Office；不是原二进制 DOC/XLS 文件或原模板版式的逐字节复制。Excel 单表超出行数上限时提示改用完整 CSV/CHD，不静默截断。

图像尺寸范围为宽 400–8000、高 300–8000 像素，总像素最多 2400 万。当前视图会按自定义尺寸缩放，不是改变计算数据。报告数值使用完整数据，图形为保持极值的显示抽样。

## 批量输出

“批量输出”按工况分组勾选通道，支持分类选择、全选、全不选、反选；原生复选框可通过键盘焦点和空格操作。选择索引固定对应原工况/通道，不按重排后的行号取数据。

- 批量图像：五种格式、宽高、自动/自定义频率范围、整周期及当前/全时段选项。
- 批量通道数据：每个选择生成单独 CHD，默认输出完整有效波形，不套用键相截短。
- 汇总 Excel / Word：按选择生成逐通道统计、谱峰及图表；汇总 Excel 不将显示采样作为完整数据表。若需要所有完整点数，使用批量 CHD。
- 默认不把主通道滤波用于其他通道；只有明确勾选“将主通道滤波参数用于批量通道”才应用，参数不适配的通道记入错误清单。
- CON 可导入或粘贴。每行是起止秒数，行数对应全部工况或所勾选工况，均按页面顺序。依原批量导出器的逻辑，负数/逆序等无效起止对表示该工况保持全时段；有效范围按通道长度截取。
- 无键相通道在批量整周期模式下按非整周期处理，实际参数写入结果清单。
- 后台串行执行，显示当前项、进度和错误。取消请求在当前项处理结束后停止，不把半成品当完整结果。
- 完成后下载 ZIP，含命名后的各项文件、分析清单、错误清单。部分项失败时明确显示错误，可下载其余成功结果；全局生成失败则不提供假完成包。

输出位置由浏览器下载设置控制；批量以 ZIP 交付，保留内部分类命名，不写入任意服务器路径。服务重启后任务状态不恢复，可重新发起生成。

## 文件与运行信息

文件属性提供路径、时间、大小、SHA256、试验/工况、采样配置及完整通道元数据。外部 CHD 导入要求明确填写采样率，可设置标题、单位和颜色；仅接受数值波形，不能将含表头的频谱结果 CHD 冒充波形。

会话内的分析、状态与输出日志可下载 TXT。JSON 分析记录继续保留输入哈希、参数、滤波链、叠加/趋势/甩负荷、标注和算法版本。
