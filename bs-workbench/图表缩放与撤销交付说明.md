# 图表缩放与撤销交付说明

版本 0.6-chart-navigation，2026-11-08。依据《功能保留清单》W-02/W-04 及《功能入口与源码证据》的相关命令接入，本轮未运行测试或浏览器验收。

此文为 0.6 历史说明；0.9 已加入默认视区自动联动及完整通道显示，当前行为请以《波形与频谱页面交付说明》为准。

## 操作入口

图表工具栏“图表操作”下拉框与图中右键提供模式选择。

| 图表 | 操作 | 使用方法 |
|---|---|---|
| 波形 | 框选放大 X / Y / XY | 选择模式，按住鼠标拖出范围，松开生效；X 只改变横轴，Y 只改变纵轴，XY 同时改变两轴 |
| 波形 | X 轴平移 / XY 轴平移 | 选择模式，按住拖动；XY 平移保留纵轴跨度 |
| 频谱 | 框选放大 X / XY | 选择模式并拖动框选；XY 模式可独立调整幅值轴 |
| 频谱 | X 轴平移 | 按住拖动横向移动当前频率范围 |
| 两图 | 滚轮 | 默认缩放 X；在 Y 模式缩放 Y，在 XY 模式缩放两轴；按 Alt 使用 Y 缩放 |
| 两图 | 撤销缩放 / 平移 | 每次返回当前图上一步坐标范围；两图的历史分别保存；图表焦点下 Ctrl+Z 同样生效 |
| 两图 | Esc | 取消本次尚未松开的框选或平移，坐标返回拖动前，不增加撤销记录 |
| 波形 | 重绘全图 | 用当前滤波、置信度、FFT 模式重新分析完整有效通道；整周期启用时仍按键相取点，并清空旧视区历史 |
| 频谱 | 重绘全图 | 重绘当前分析区间的全部频谱，纵轴恢复自动范围并清空频谱坐标历史 |

波形顶部原“复位视图”按钮及平移模式双击仍只恢复当前分析区间的视图。“重绘全图”是另一操作：波形会重新分析完整有效通道。两者不代替逐步撤销。

频谱低频范围快捷选择可逐步撤销。切换原始数据叠加保留当前坐标和历史；重新计算或切换通道后开始新的坐标历史。标注和游标模式继续保留，缩放时标注锚点仍是数据坐标。

## 视区与分析区间

图表工具行显示当前 X/Y 视区。坐标缩放本身只改变显示；右侧统计和 FFT 仍对应最近一次成功分析的实际区间。

波形工具栏和右键中的“按当前视区分析”将当前横轴范围换算为采样点，重新分析并同步更新统计、频谱及导出。整周期模式继续在范围内选取完整周期；范围过小或键相不足时提示，不伪造结果。

原版 `ZoomCwgraph2` 会自动调用 `SetWaveParam`、`FFTProc`，并有最小区间限制；这条自动联动还没迁移，当前提供的是显式分析按钮。因此 W-02 仍是部分实现，不能记为已通过原版等价验收。

## 交付状态

本轮只修改浏览器版，原桌面源码和数据不变。按用户要求未运行测试，当前由用户操作验收。默认 97% 峰峰值、默认键相整周期、矩形窗及不在 FFT 前主动去均值的口径继续保留。
