# 轴心轨迹原版排版

版本 0.17-orbit-classic-layout，2026-11-10。按用户提供的原版截图调整 `/specialty?module=orbit`，不修改轨迹配对、滤波、采样点选取及相关算法。

页面上方为完整试验类型、工况、X/Y通道总标题。左侧约58%宽度，上下分别显示X波形、Y波形，各自标题含通道名和单位；右侧约42%宽度显示“二维轴心轨迹”，纵向居中。白底、蓝色默认曲线、浅色网格和灰色坐标外框；未新建图时也保留三幅空坐标区域。

新建参数从常驻侧栏移入弹窗，原文件→类型→工况→X→Y逐级启用及灰显保留。原输入、参数和事件处理复用，取消不会替换已生成图。统计结果、图例及各图详细操作在“参数 / 结果明细”中保留。

上方紧凑工具栏保留新建、标题、坐标、滤波、恢复、输出和配置入口；新增图表对象选择，可对X波形、Y波形、二维轨迹分别使用X / Y / XY缩放、平移、撤销和重绘。原图区右键、滚轮操作和波形范围联动继续复用。图内读数移到状态栏，减少图表下方占用。

当前视图图像导出按总标题、左侧双波形、右侧轨迹的实际位置合成，不再使用上下顺排图表。Word / Excel及数据输出保留既有入口。总标题及波形标题取自该图实际生成数据的元信息，避免未提交的新建草稿改变当前图通道名；多视图标签使用总标题。

`static/orbit-layout.js` 和 `static/orbit-layout.css` 仅在轴心轨迹模块生效，其他专项页不使用此布局。后端只增加X/Y通道来源元信息，没有改变数值处理函数。绘图自动刻度使用规整显示范围，手动缩放范围保留。

本轮按用户此前要求未运行功能测试、浏览器操作、截图检查、语法检查或数值回归，仅通过原启动脚本重启服务交付。未声称逐像素相同，验收状态不变。原桌面源码和 `frontend-review` 基线未修改。修改前文件备份位于 `delivery-backups/before-orbit-layout-20261110-210030/`。
