# FastAPI 后端升级

版本：0.12-fastapi，2026-11-08。

## 已完成

- 将标准库 HTTP 服务替换为 FastAPI + Uvicorn，继续在本机 `127.0.0.1:8765` 提供页面和接口。
- `server.py` 是启动入口；`api.py` 负责路由、会话与来源校验、请求大小限制、上传、下载、静态页面和统一错误响应；`analysis_service.py` 负责文件读取、分析调度和输出结果。
- 保留原有 22 个 API 路径，JSON 字段、二进制上传格式、下载文件名与计算参数继续沿用原代码。OpenAPI 接口定义新增于 `/api/schema`，未启用依赖外部 CDN 的文档页面。
- 同步文件读取、计算和导出接口使用 FastAPI 的线程池；文件上传异步分块写入，导入后解析在线程池执行。现有计算互斥和批量导出后台任务保留。
- 继续使用本机 Host、POST 会话令牌、Origin 校验、256 MB 文件限制及原有安全响应头。上传中断或解析失败会清理未完成文件。服务保持单进程，避免多个进程各自持有令牌、图表快照和批量任务。
- 项目 `.venv` 安装 FastAPI 0.162.2、Uvicorn 0.54.0，版本写入 `requirements.txt`。启动器检查新依赖和服务版本；原有启动、停止、重启 CMD 入口保留。
- 启动错误提示脚本移动为 `static/startup.js`，使其符合原有禁止内联脚本的 CSP；页面外观及操作入口保持既有实现。

## 诊断记录

- 新 Python 文件语法检查及启动脚本 JavaScript 语法检查完成。
- 对旧服务与新业务层进行 AST 静态核对：文件定位、元数据、核心分析、输出补充等函数保持相同代码。
- 原有 22 个 API 路径均已注册，FastAPI 导入及 OpenAPI 生成完成。
- 已由原重启脚本启动新服务；健康接口报告 FastAPI / Uvicorn、版本 0.12-fastapi。
- 启动数据接口能够初始化会话并列出样本；主页面、长图和 12 项配套静态资源均可读取。
- 遵照用户此前要求，未运行业务功能测试套件、数值回归、浏览器操作或像素对照。本轮不扩大任何验收范围。

## 后续 Agent 接入边界

本次完成接口框架和业务分层。模型密钥、模型连接、对话界面、工具参数模型、Agent 编排、流式回答及执行记录均尚未实现。后续对话请求可使用异步接口，调用计算时转交业务层执行；不能将本次框架升级视为已具备 Agent。

## 备份与启动

升级前的服务、启动器、依赖清单和说明保存在 `delivery-backups/before-fastapi-20261108-230659/`，该目录也保存修改前的首页。原桌面程序、`frontend-review` 基线和原始示例数据未修改。

启动仍使用根目录 `启动浏览器分析版.cmd`。服务重启会生成新会话令牌，已打开的网页需要刷新；运行中的批量任务应在重启前完成。关闭网页不会停止本机服务。
