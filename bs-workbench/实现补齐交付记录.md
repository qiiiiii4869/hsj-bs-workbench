# 实现补齐交付记录

版本 0.15-workflow-completion，2026-11-10。

本轮针对上一版明确存在的实现缺口继续编写代码，不把页面入口本身当成功能完成。以两份原版文档、原 C++ 处理代码及 NI 开发头文件为依据，更新了覆盖70项功能分组的 `功能实现索引.json`。索引记录实际代码文件、处理函数和页面入口，不是测试通过记录。

## 新的启动入口

运行根目录 `启动浏览器分析版.cmd`，默认打开 `http://127.0.0.1:8765/desktop`。兼容原单页地址 `/`、`/strip`、`/waterfall`、`/specialty`；接口文档仍在 `/docs`。

程序内多视图支持新建、切换、关闭当前 / 全部关闭、平铺、层叠、移动 / 调整尺寸、最小化 / 恢复、恢复上次窗口、刷新当前视图。各子视图保留自己的数据和操作状态。Ctrl+F4 关闭当前视图；能接收快捷键的浏览器上下文中支持 Ctrl+Tab 切换，按钮入口始终保留。退出命令通过本机会话接口取消任务并停止服务，不再仅尝试关闭浏览器标签。

## 特别保留的原版计算语义

轴心滤波从 `AxisOrbit.cpp` 和 `NiMath.h` 核对：前补长度是 `min(N,3072)`；原高通调用实际使用低截止字段，原带通 / 带阻五参数调用把所选阶数传为上截止频率，并使用库的缺省5阶；两侧原调用使用共享采样率。页面默认“原版参数口径”，另有明确的“按填写参数（修正原版调用）”选项。原版调用产生无效截止频率时会报错，不伪造滤波结果。

动平衡前侧插值在已知后侧采样率时保留原 `re_timeB` 对后侧采样率的引用，未取得另一侧采样率时使用当前侧；原代码未初始化和越界位置采用有限边界处理，不复制崩溃行为。一般相同采样率场景的取点、长度减一、向下取2次幂、转频定位和双幅显示均保留。

相关输出顺序依据 National Instruments《LabWindows/CVI Advanced Analysis Library Reference Manual》5-49页 Correlate 定义核对，并结合项目 `CNiMath::Correlate` 调用保留未归一化的完整相关序列。此处是依据定义修改实现，没有执行数值对照。

## 验收状态与边界

遵照用户指示，本轮没有执行单元测试、接口业务测试、浏览器测试、脚本语法测试、NI数值回归或Office转换测试。操作新版本服务时只使用启动器自身的就绪等待。Office转换和浏览器目录授权在用户实际选择输出时才执行，没有提前启动Office或选择用户目录。

`功能实现索引.json` 给出70项分组的代码入口；`migration-ledger.json` 保留139命令、45窗口、650控件、276事件的原始证据和实现引用。原版NI控件内部默认行为、控件逐像素外观及数值一致性仍属于用户验收，不将未运行的结果记录为通过。原版已注释的相关泛化命令、空手册函数、不可达框架候选按原基线保留说明，不虚构成可用功能。

既有标注拖动验收记录保持不变，整程序完全替代验收标志保持false，待用户验收后更新。原桌面源码及 `frontend-review` 基线未修改。

## 补充收尾

多文件导航已实现为实际多文件树，而不是单文件树外加文件下拉框。各文件 / 类型 / 工况 / 通道右键批量集合对应自己的文件元数据和导出参数；目录输出可逐文件写入，不要求用户手工解包ZIP。效率计算方式切换保留仍适用的通道选择；盘车两组配置分别联动。动平衡参数表为实际可编辑表格，非仅输出一张只读结果表。选择保存目录时取消操作保留之前的保存设置。
