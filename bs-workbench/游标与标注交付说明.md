# 游标与标注操作说明

版本：0.5-cursors；日期：2026-11-07。

## 入口与操作

每幅波形、频谱图下方新增“图表操作”模式选择和标注按钮，图内右键也可打开同一组操作。

- **捡取浮动点**：选择后在图内单击或按住拖动，显示横纵捡取线和自由坐标。它不吸附曲线，也不表示某个采样值。
- **捡取临近点**：选择后单击或拖动，从当前计算波形或频谱的完整数据中，按图面距离读取临近数据点。读数显示精确坐标、波形采样点序号或频谱序号。序号从 0 开始；不是从全览抽样点中选一个代替。
- **添加标注**：先用“捡取临近点”定位，点击“添加标注”，输入文字并保存。浮动点未绑定采样值，不能直接作为自定义标注锚点。取消或 Esc 不提交文字。
- **修改/删除**：展开图下标注列表，可修改文字或删除单条。移动模式中双击文字框也可修改。
- **移动标注位置**：0.6.1 起保存后直接按住文字框拖动即可，不必先切换模式。文字框优先于拾取、缩放和平移响应拖动，只移动文字位置，锚点保持在原数据点。双击文字框可修改文字；按 Esc 取消尚未松手的移动。原“移动标注位置”模式入口继续保留。
- **清除标注**：清除当前图的所有标注，不影响另一幅图及原始文件。
- **标注当前范围极值**：从当前可见横坐标范围的完整计算数据中取最大、最小值，加入两条标注。该按钮是新增辅助功能。
- **浏览/平移**：按住拖动平移横轴；滚轮缩放，浏览模式双击或“复位视图”复位。缩放/平移结束后从完整数据重新提取当前范围细节。
- **保存当前图 PNG**：保存当前视图、标题、坐标、曲线及可见标注。它不是原版所有图像格式、全图或批量保存功能的完整替代。

图表可按 Tab 获得焦点；浮动点可用方向键移动，临近点可用左右键逐点移动，按 Shift 加快步进。临近点定位后按 Enter 可添加标注。

## 状态与保存

游标模式、位置和标注按“文件 SHA256、工况、通道、计算区间、窗函数、去均值设置和滤波参数”的分析指纹分别保存。切换结果不会把旧参数下的标注套到新曲线上；切回相同结果可恢复对应记录。本地存储不可用时只保留本次页面会话。

JSON 与 CSV 导出中包含标注文字、图表、坐标、文字框偏移和分析指纹。全时段 CSV 的数据范围可大于当前标注所对应的分析范围，标注仍保留其原分析指纹。

临近点和极值接口使用本机服务中的完整分析快照。服务重启或打开较多分析结果后，旧快照可能释放；此时点击“开始分析”重新获得数据，已保存的标注不会因此被删除。图表拾取目标是主计算曲线，灰色原始对照线不作为另一个拾取目标。

## 原版核对与验收状态

依据原代码中的 `SnapFloating`、`SnapNearestPoint`、`OnAnnotation`、`OnCancelAnnotations`、`OnAdjustAnnotationPlace` 接入对应能力。原版控件的具体鼠标命中规则及完整行为，仍需实际运行核对。

原程序核对目前只确认到主界面、打开文件入口及样本选择；样本加载后的窗口曾消失，尚未确认原因，没有获得完整的原版游标/标注实操证据。不能据此声称已经与 NI 控件逐项等价。

原版有两个不同的标注入口：`ID_ANNOTATION` 是自定义文字标注；`ID_Annotations` 关联甩负荷趋势分析。本轮未把它们合并，也未用新增“标注当前范围极值”代替甩负荷专用流程。后者继续保留待迁移状态。

本轮按用户此前要求不运行网页测试、不做网页截图、不执行自动化测试。当前状态为实现接入、交用户验收，完整程序替代验收仍未通过。
