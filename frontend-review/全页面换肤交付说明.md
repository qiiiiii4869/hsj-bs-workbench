# 全页面浅色换肤版

日期：2026-11-07。本轮延续已确认的首轮样式，保持各页面原有布局。

## 使用

关闭正在运行的数据分析程序，双击根目录的 `运行换肤测试版.cmd`；该入口已指向 `build-analysis/out/Skin-Preview-AllPages/ScanAnalysis.exe`。

首轮程序仍保留在 `build-analysis/out/Skin-Preview`。原有 `Trial-Run` 和 `测试系统实例` 的程序未替换。新版本仍依赖本机已配置的 VC80/NI 运行环境。

## 实现约束

- 保留资源模板坐标、控件 ID、按钮顺序、消息处理函数和原有分析流程。
- 原布局源码、几何计算文件及资源模板的几何定义未调整。
- 对话框本身保留原资源字体用于对话框单位换算；仅替换标准子控件字体的字形，保留原高度、粗细等属性。字体对象由窗口持有至销毁，避免使用临时字体。
- 通用白色背景通过可复用画刷绘制。颜色预览、用户选择字体、反射绘制的编辑框以及系统文件选择框保留各自处理方式。
- 不改变采样数据、滤波／FFT／工程算法、坐标范围、精度、投影、相机及用户曲线配色。
- 公共原生按钮、复选框和下拉框继续使用系统控件，保留键盘、焦点、默认按钮和禁用状态行为。
- 首轮源码及可执行程序备份在 `frontend-review/skin-backup-before-all-pages-20261107`。

## 编译与验收状态

Release／Win32 构建通过：62 个 C++ 编译单元、资源、链接和清单嵌入均完成。

按用户要求，本轮没有启动应用，没有执行运行、界面、功能或数值测试。所有页面的实际显示、文字适配和功能行为由用户验收。

## 主要实现

- `HSJDialogAppearance.h`：标准子控件字体持有、共享对话框基类、白色底色及三维图显示属性。
- `stdafx.h`：向应用声明公共外观层。
- `MainFrm.cpp`：公共对话框基类的运行时类型和绘制消息映射。
- 应用对话框 `.h/.cpp`：基类及对应调用由 `CDialog` 接入 `CHSJDialog`；底层仍为 MFC CDialog，原处理逻辑保留。
- 七个专用分析视图：初始化显示属性，复用背景画刷；各自保存字体生命周期。
- `StripChart/boxingView.cpp`、`CatListBox.cpp`：现有自绘代码中的字体和颜色调整。

既有文件保留原编码；首轮波形视图仍为带 BOM 的 UTF-8。新增共享头文件为 ASCII。
