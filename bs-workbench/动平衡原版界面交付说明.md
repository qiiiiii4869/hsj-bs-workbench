# 动平衡原版界面

版本 0.16-balance-classic-layout，2026-11-10。依据用户提供的两张原版截图及 `DynamicEquilibrium.cpp` 改为专用动平衡页面，替换此前通用专项页面的侧栏 / 顺排图表布局。

## 页面结构

- 顶部紧凑命令栏，其下显示配重前 / 后采样周期数，以及原始振动（红）、试重振动（蓝）、试重块（青）、配重块（品红）、配重分解（浅粉）图例和旋转方向。
- 左侧上、下固定为配重前 / 配重后波形；右侧为跨两行的动平衡圆形矢量图。尚未加载的一侧始终保留空坐标图，不会因另一侧更新而消失。
- 底部固定五行参数表：原始参数、试重参数、配重方案、分解1、分解2。字段对应转速、总振值双峰、转频双幅值、相位、重量与角度。只读区域灰底，配重结果浅黄底，支持编辑字段的 Enter / Escape / Tab / 上下键操作。
- 页面不再常驻原始幅相、试重等大侧栏。数据加载使用独立窗口，按文件 → 试验类型 → 参数类型 → 通道逐级启用；取消及加载失败保留当前图。

## 使用

1. 在多视图工作区打开动平衡，点击“加载配重前数据”，在小窗口逐级选择并确定。配重后使用相同流程，数据来源独立。
2. 在对应波形上拖动选取周期，或双击起点后移动并单击终点；周期边界对齐键相点。顶部更新周期数，最多16个完整周期。
3. 点击对应侧“分析”，或聚焦该波形后按 Enter。结果自动填入表格，波形放大到该分析段，右侧立即显示该侧振动矢量及参考圆；不要求先完成另一侧。
4. 在试重参数行填写试重重量和角度。具备两侧幅相后可计算配重方案，再填写分解1 / 2角度计算分解重量。
5. 波形右键可加载、选择周期、框选放大、输入精确时段、分析、取消选择、撤销缩放、重绘；滚轮缩放。取消周期选择保留该侧已计算结果。
6. 保存视图会包含顶部图例 / 周期计数、左侧双波形、右侧矢量图和底部参数表，支持五种图像格式；参数表支持文本及 Word / Excel 输出。DOC / XLS 继续通过本机 Office 转换。

## 坐标与数据

参考圆半径采用两侧转频双幅值的较大值，与原版 `DrawDynEquGraph` 的输入口径对应。零度在右，方向选项确定正相位和90度标记位置；顺时针时正相位画向下方，匹配用户第二张截图。使用等比例XY绘制避免圆变为椭圆。试重块、配重块及分解位置画在圆周上，不把重量和振动幅值混用为同一数值半径。

复用原有 `balance_sample / balance / balance_decompose` 后端计算。本轮没有改 FFT 幅值、相位、插值或配重计算公式。波形预览增加完整数据快照，放大后向 `/api/chart` 读取所选时段细节，避免只放大概览抽样。配置保存文件SHA256，载入时重新读数据并检查原文件归属。

保留原菜单地址 `/specialty?module=balance`，服务端为其返回专用页面；也可直接访问 `/balance`。多视图工作区及主页面菜单不需要改操作习惯。
